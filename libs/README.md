# WealthLab 8 Libraries

This folder should contain the required WealthLab 8 DLL files for building the project.

## Required Files

Copy the following files from your WealthLab 8 installation directory (typically `C:\Program Files\Quantacula, LLC\WealthLab 8\`) into this folder:

- `WealthLab.Core.dll`
- `WealthLab.AdvancedSmoothers.dll`
- `WealthLab.IchimokuCloud.dll`

## Note

These DLLs are not distributed with this repository due to licensing. You must have a valid WealthLab 8 installation to obtain these files.
